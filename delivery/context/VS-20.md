## Security boundary
- Private generated objects remain authoritative by scoped object identity + content hash, never by public URL.
- Publishing URLs are short-lived egress capabilities, scoped to Workspace/Brand/object and intended only for deterministic channel adapters.
- The encoder may invoke one configured FFmpeg executable directly, never through a shell. No external/untrusted text becomes command, filename, filter, protocol or process option.
- Read/encode/egress operations fail closed on scope, hash, type, size, expiry or process-result mismatch.

## Implementation direction
1. Extend the generated-media boundary with scoped read, deterministic lookup and publishing URL issuance.
2. Add a provider-neutral `ReelEncoderPort`.
3. Add a bounded FFmpeg adapter using direct process execution and Kairo-generated temporary inputs.
4. Build `PublishableCreativeMediaService` to validate stored artifacts, reuse encoded Reels, store new MP4s privately and return typed publishing media items.
5. Keep the current Instagram adapter unchanged unless tests reveal a compatibility regression.

## Stop conditions
Stop and return to governance if implementation would require arbitrary shell execution, public-bucket access, new provider credentials, autonomous publishing, production Brand skill execution, database migration, release workflow changes, deployment or production enablement.
