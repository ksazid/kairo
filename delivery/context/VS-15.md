## Existing baseline

- `packages/domain/src/publishing.ts` owns deterministic channel capabilities, commands, attempts and published-post lineage.
- `packages/domain/src/publishing-service.ts` schedules only human-approved current versions.
- `apps/worker/src/publishing.ts` executes deterministic jobs without model/agent authority.
- `apps/worker/src/publishing-adapters.ts` already publishes LinkedIn text and one Instagram image through provider adapters.
- `apps/api/src/publishing-postgres-store.ts` persists channel accounts and publish commands.
- `apps/api/src/publishing-execution-postgres-store.ts` claims due commands for the worker.

## Critical gap

The current Postgres execution store always returns `mediaUrls: []`. Therefore the existing Instagram image adapter cannot receive actual media from the authoritative scheduled-command path. VS-15 must close this gap before claiming rich Instagram publishing support.

## Provider behavior

Meta's official Instagram API collection documents:
- Reels: `media_type=REELS` + public `video_url`, monitor container `status_code`, publish only after `FINISHED`.
- Carousels: create carousel-item children, create `media_type=CAROUSEL` parent with child IDs, then publish parent.

VS-15 supports image-only carousel children. Mixed video carousel children are deferred.

## Invariants

- Human approval remains required.
- Only the approved current Content Version may be scheduled.
- Credential values remain infrastructure secrets; domain/API state contains only credential references.
- Media URLs are persisted because they are required provider inputs, but must never contain credentials or private-network targets.
- The worker re-validates public HTTPS media URLs at the provider boundary.
- Unknown publication outcomes remain unknown and are not blindly retried.
- Provider correlation IDs are retained when available.
- No agent or model may directly publish.

## Exclusions

No OAuth, Insights, UI changes, Stories, mixed-video carousels, media generation/transcoding, release, deployment or production enablement.
