## Provider rules

### RSS / Atom

Generic feed definitions are configuration. Industry-specific feed parsing code is forbidden.

### Hacker News

Official v0 API only. Internal item fan-out must be bounded and cacheable.

### Bluesky

Public cached AppView only. No login/session/token.

### YouTube

Official Data API only. Key injected into the adapter from infrastructure configuration; never copied into ToolRequest, Brand context, logs, prompts or provenance.

## Hard limits

- max external results returned per provider request: 20;
- no provider may paginate in VS-13;
- adapter timeout must honor the Kairo request timeout;
- response payloads must be size-bounded before parsing;
- HN item inspection must have an explicit per-discover ceiling;
- provider failure is isolated and observable through structured result/error metadata, not swallowed as fake success;
- no secret-like fields may cross AgentContract ToolRequest validation.
