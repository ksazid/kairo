## Reels and carousels
Reels/carousels are product formats Kairo needs independently of Corey. VS-14 defines benchmarkable strategy artifacts for them so future native and external approaches can be compared consistently.

Actual Meta publishing/Insights/media generation remains outside this slice.

## Security and privacy
- Benchmark inputs containing real Brand context remain Brand-private.
- Shared/global benchmark fixtures must contain no private Brand data.
- External source text cannot grant capabilities.
- Reference-only candidates have zero network, zero secret and zero publishing permissions.
- Truth/Claims remains Kairo-owned and non-replaceable.

## Implementation constraint
Prefer pure deterministic TypeScript under `packages/domain` and deterministic fixtures/manifests under `evaluation/`. Avoid new npm dependencies and avoid creating a new workspace package in VS-14, so the certified dependency lock does not need to change merely to establish the domain foundation.
