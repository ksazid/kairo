## Product invariants

- Avatar/Presenter is optional per Brand.
- It is a Brand sub-surface, never primary navigation.
- Happy path remains short: Brand → Avatar → Create avatar → review/accept suggestions → Create & Save.
- Test Clip is optional and same-surface.
- Presenter selector appears only when eligible; default is `None`.
- Kairo may recommend Presenter use but never force it.
- Preview must show exact final media.
- Approve & Lock freezes exact asset/copy/version lineage.
- Publishing remains deterministic, human-approved and provider-capability-bound.

## Engineering invariants

- Authoritative Presenter state belongs to Kairo, scoped by Workspace + Brand.
- External providers are replaceable adapters and cannot become tenant/auth/publishing authority.
- Provider credentials are never returned to the web client or put in prompts/domain state.
- Reference/generated media is private by default.
- Provider output is untrusted until validated and persisted under correct Brand scope.
- No cross-Brand Presenter read/select/render path.
- Production must fail closed when no healthy Avatar provider is configured.
