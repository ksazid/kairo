# VS-02 — Brand Brain and Knowledge

Status: Discovery package prepared — awaiting typed scope/policy/implementation approval

## Goal
Give each Brand an inspectable, correctable Brand Brain and governed private knowledge sources.

## Requirement IDs
- FR-03
- FR-04

## User-visible outcome
A user can confirm/correct Brand identity, audience, positioning, voice, goals, boundaries and knowledge while seeing material inferred versus confirmed facts.

## In scope
- Brand Brain model and editing flows.
- Material-field states: inferred, confirmed and stale/needs-review.
- URL, website, note, pasted-material, research/product and approved document-source records.
- Source provenance, enable/disable/replace/remove lifecycle and deletion propagation contract.
- Private S3-compatible object-storage port where file support is activated; vendor remains deployment-bound.
- Brand-scoped relational retrieval metadata and privacy boundaries.
- SSRF-safe URL-ingestion boundary.
- Document quarantine/type/size/malware-scanner contract before a document can become active knowledge.
- Design-baseline-compliant Brand Brain/profile/knowledge UI with loading, empty and error states.
- Audit events for material Brand Brain/source changes.

## Non-goals
- Global Hunter or Agent Reach runtime.
- Hermes execution.
- Qdrant/PgVector provider promotion; DEC-003 remains VS-03.
- Campaign/content generation.
- Executable third-party Skills.
- Cross-Brand learning or aggregate training.
- Publishing, metrics or production deployment.

## Dependencies and gates
- VS-01 is certified and merged and provides Workspace/Brand identity and authorization boundaries.
- DEC-006 must be approved before runtime implementation: private-source deletion and derived-memory propagation.
- Any activated document ingestion must carry content/type/size/quarantine/malware controls before certification.
- Object-storage vendor selection remains adapter-bound until a deployment ADR.
- Release and production-enable remain separate exact-SHA approvals.

## Proposed DEC-006 policy
When a private source is removed/replaced, delete raw source content and source-only derived retrieval data; retain only a content-free audit tombstone; preserve facts explicitly confirmed by the user; mark AI-inferred facts with no remaining active support as stale and exclude them from authoritative AI/retrieval context until reconfirmed or re-supported. Replacement creates new provenance/version links rather than rewriting historical evidence.

See `planning/VS-02-POLICY-DECISIONS.md`.

## Acceptance criteria
1. Every Brand Brain and Knowledge record is Workspace/Brand scoped and server authorization is rechecked on every operation.
2. Material AI-inferred facts remain distinguishable from user-confirmed facts.
3. Users can correct important Brand Brain fields and corrections are auditable.
4. Private sources can be enabled, disabled, replaced or removed with auditable state.
5. Approved DEC-006 deletion propagation is deterministic and covered by integration tests.
6. No private Brand material enters Global Intelligence by default.
7. URL ingestion cannot reach disallowed/private network targets.
8. Documents cannot become active knowledge before required type/size/quarantine/malware controls pass.
9. Retrieval metadata is always Brand scoped; no unscoped private retrieval API exists.
10. Responsive/accessibility checks cover loading, empty, validation and recoverable-error states.
