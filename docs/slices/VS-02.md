# VS-02 — Brand Brain and Knowledge

Status: Proposed for scope approval

## Goal
Give each Brand an inspectable, correctable Brand Brain and governed private knowledge sources.

## Requirement IDs
- FR-03
- FR-04

## User-visible outcome
A user can confirm/correct Brand identity, audience, positioning, voice, goals, boundaries and knowledge while seeing material inferred versus confirmed facts.

## In scope
- Brand Brain model and editing flows.
- URL, note, pasted-material and approved document-source records.
- Source provenance, enable/disable/remove lifecycle and deletion propagation contract.
- Private S3-compatible object-storage port where file support is activated.
- Brand-scoped retrieval metadata and privacy boundaries.
- Design-baseline-compliant profile/knowledge UI.

## Non-goals
- Global Hunter.
- Campaign generation.
- Executable third-party Skills.
- Cross-Brand learning or aggregate training.

## Dependencies and gates
- VS-01 must be complete enough to enforce Workspace/Brand identity.
- Any executable file ingestion must carry content/type/size/malware controls before certification.
- Object-storage vendor selection may remain adapter-bound until deployment ADR.

## Acceptance criteria
1. Every Brand Brain record is Workspace/Brand scoped.
2. Material AI-inferred facts remain distinguishable from user-confirmed facts.
3. Users can correct important Brand Brain fields.
4. Private sources can be disabled/removed with auditable state.
5. No private Brand material enters Global Intelligence by default.
6. Responsive/accessibility checks cover loading, empty and error states.

## Governance
- Lifecycle: proposed.
- Implementation mode: specification-only.
- Scope, policy and implementation approvals remain pending.
- `.github/workflows/release.yml` remains protected.
- Superpowers begins only after the slice is approved/activated with runtime implementation permission.
