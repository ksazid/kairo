# VS-76 — Multi-source Meta Onboarding

## Status
Approved for runtime implementation by Sazid Khan on 2026-08-22 as Batch 3 of the approved Instagram completion work.

## Requirements
- FR-01 — Brand onboarding
- FR-02 — Brand Brain
- FR-15 — Publishing
- FR-16 — Channel connections

## Outcome
Kairo lets a user create a Brand from any combination of an optional website, direct Instagram Login, Facebook Login with linked Instagram, and Facebook-only Page access, while preserving one replaceable publishing boundary and secure Brand-scoped credentials.

## In scope — Batch 3 tasks 21–30
1. Govern independent multi-select source choices and provider/token boundaries.
2. Add a Brand-scoped connection-plan contract for website, direct Instagram, Facebook+Instagram and Facebook.
3. Add accessible, responsive multi-select cards to first-Brand and additional-Brand onboarding; create the Brand before OAuth continuation.
4. Add direct Instagram Login for an Instagram Professional account without requiring a Facebook Page.
5. Generalize connection persistence for provider/auth method, optional Page metadata, reconnect, disconnect, expiry and credential rotation.
6. Retain the existing Facebook Login + linked Instagram path as an explicit onboarding choice.
7. Add Facebook-only Page discovery, selection, connection and health.
8. Add the Facebook channel and a bounded Facebook Page publishing adapter; unsupported formats require manual handling.
9. Keep website ingestion and each connected channel independently visible in Brand Brain, with destination deduplication.
10. Add unit, integration, UI, migration, security, tenant-isolation, accessibility and combination tests.

## Acceptance criteria
- [x] All four choices are independently selectable and website can accompany every connection combination.
- [x] Direct Instagram Login supports a Professional account without Page metadata.
- [x] Facebook+Instagram and Facebook-only flows use explicit Page selection.
- [x] OAuth continuation is Brand-scoped, replay-resistant and recoverable after cancel or failure.
- [x] Tokens are encrypted at rest, never exposed to the browser or logs, and rotate safely on reconnect.
- [x] A Brand has at most one active publishing destination per channel/account reference.
- [x] Brand Brain preserves distinct website, Instagram and Facebook source health.
- [x] Publishing routes through replaceable adapters and rejects unsupported Facebook formats safely.
- [x] Focused and full verification pass before a draft PR is offered for exact-SHA approval.
