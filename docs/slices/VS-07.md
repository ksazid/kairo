# VS-07 — Channels, Calendar and Publishing

Status: Approved for runtime implementation under AUTH-001 and DEC-004

## Goal
Connect approved channel accounts, schedule approved Content Versions and publish deterministically where pilot APIs permit.

## Requirement IDs
- FR-05
- FR-14
- FR-15

## User-visible outcome
Users can view a simple cross-Brand calendar, schedule approved content and see explicit published/failed/manual states for Instagram and LinkedIn pilot paths.

## In scope
- Channel account model and least-privilege OAuth/token storage.
- Calendar filters by Brand/Campaign/channel/status.
- Deterministic publish commands/adapters, idempotency and retries.
- External post IDs, failure/reconciliation states and operator retry.
- Manual publishing fallback for unsupported paths.
- Rate-limit and safe degradation handling.

## Non-goals
- Agent-held social credentials.
- Unrestricted autonomous publishing.
- Paid ad execution/spend.
- Enterprise campaign-management suite.

## Dependencies and gates
- VS-06 approval enforcement is required.
- DEC-004 approved: capability-gated official adapters for both channels, with explicit manual fallback.
- Social credentials remain accessible only to deterministic adapters.
- High-risk security review required before certification.

## Acceptance criteria
1. Only an approved Content Version can enter a publishing command.
2. Editing approved content requires reapproval.
3. Retries are idempotency-safe and failures never appear successful.
4. Unknown external state after timeout is reconciled explicitly.
5. Unsupported channel capability degrades to clear manual workflow.
6. Agents cannot access OAuth tokens or bypass publish policy.

## Governance
- Lifecycle: ready-for-implementation.
- Implementation mode: runtime-enabled.
- Scope, policy and implementation approvals are recorded; exact-SHA certification remains pending.
- `.github/workflows/release.yml` remains protected.
- Superpowers begins only after the slice is approved/activated with runtime implementation permission.
