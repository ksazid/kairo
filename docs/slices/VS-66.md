# VS-66 — Closed-World Claim Generation Contract

## Objective

Correct the generation-contract defect revealed by Run B without modifying or rescoring Run B evidence. Both Kairo Native and Corey shadow lanes must operate under one identical closed-world factual-support rule before a fresh qualification attempt is allowed.

## Evidence that triggered the slice

Run `vs23-qualification-20260819-b` completed four paired Native/Corey executions. The governed VS-65 evaluator later marked `motorcycle-carousel-03` Truth-failed for both lanes because both outputs introduced unsupported technical/mechanical detail. The failure proves Claim-ID lineage alone is insufficient to prevent plausible but unsupported factual embellishment.

Run B and its evaluator evidence remain immutable.

## Contract

Version: `closed-world-claims-v1`

Both Native and Corey must receive the exact same rules:

1. Treat supplied benchmark Claims as the closed world of factual support.
2. Every concrete factual, technical, mechanical, performance, compatibility, specification, feature, maintenance, safety, price, or availability assertion must be directly entailed by at least one supplied Claim.
3. Do not infer plausible details from general knowledge, product category, audience, or untrusted reference material.
4. If a detail is not supported by a supplied Claim, frame it only as a question, comparison criterion, or thing to verify; never state it as fact.
5. Marketing framing and non-factual connective language may not add factual meaning beyond the supplied Claims.

The contract version and exact rules are included in `marketingShadowInputFingerprint`, so evidence produced under this contract cannot collide with Run B fingerprints.

## Invariants

- `evaluation/marketing-lab/benchmark-cases.json` is unchanged.
- Corey remains pinned to `coreyhaines31/marketingskills` commit `7868cb9251fad80a73d26e488a5ad5f6c4a9f335` and the existing Social skill blob.
- Native and Corey use the same Claims, required Claim IDs, provider/model route, pricing policy, output schema, cost ceiling, timeout and pacing.
- No Hermes activation.
- No benchmark threshold changes.
- No VS-65 evaluator rubric changes.
- No human scoring or deterministic promotion verdict in this slice.
- No production execution is authorized by implementation of VS-66.

## Regression coverage

The qualification tests must prove:

- Native and Corey instructions contain the exact same `closed-world-claims-v1` instruction string.
- The contract explicitly covers technical/mechanical/performance assertions and the question/verification fallback.
- `motorcycle-carousel-03` retains its original two fixture Claims exactly.
- The shared benchmark fingerprint remains a 64-character SHA-256 and now includes the closed-world contract version/rules.
