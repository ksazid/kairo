# VS-103 — Brand Brain V2 and Brand Intelligence Topic Graph

## Objective

Turn the evidence already captured by the shared Source Intelligence pipeline into a richer, provenance-aware Brand Brain and a deterministic, versioned Brand Intelligence Topic Graph that Hunter can consume.

## In scope

- Brand Brain V2 field catalogue covering sector/subsector, products/offers, authority areas, core/related/excluded topics, preferred channels/formats, visual patterns, terminology, competitors, geography, language, evergreen/freshness guidance.
- Explicit confidence and source provenance for inferred intelligence.
- Versioned Topic Graph nodes with topic, aliases, parent, priority, confidence, sourceIds, freshness, preferred/excluded and authority signals.
- Deterministic graph fingerprinting so a new version is created only for material changes.
- Configurable sector packs: generic, AI/tech, Umrah, motorcycles, IAS/UPSC.
- Sector packs are low-precedence seeds only; confirmed Brand evidence wins and excluded topics win conflicts.
- Persistence schema for graph versions and a nullable graph-version lineage field on Hunter runs when such runs are persisted.
- Deterministic tests for graph construction, precedence, deduplication, no fabricated provenance and version behavior.

## Corrective revision 1.1 — in scope

- Repair unstable source hashes, bounded website sampling/provenance, partial GitHub degradation, cache freshness and optional provider configuration.
- Wire bounded media analysis and onboarding sampling into the shared Source Intelligence path.
- Persist and consume Brand Intelligence Topic Graph versions instead of leaving the graph schema dormant.
- Implement Batch 6 Hunter source-aware multi-intent queries, search-to-fetch evidence enrichment, deterministic clustering/ranking/diversity and structured Opportunity output.
- Keep `YOUTUBE_API_KEY` optional; official API mode is conditional and public fallback/unavailable states remain truthful.

## Out of scope

- Frozen UI changes.
- New scraping/retrieval pipelines.
- Automatic Hunter execution, For You actions or My Idea orchestration (Batch 7).
- Scheduler/shadow mode (Batch 8).
- New OAuth/provider authority or autonomous publishing.

## Safety and truthfulness

- The shared Source Intelligence pipeline remains the only source-ingestion path.
- Sector-pack hints never become source-backed facts by themselves.
- Missing sourceIds, confidence or authority evidence remain missing rather than being fabricated.
- User-confirmed Brand Brain fields retain highest precedence.
- Excluded topics suppress conflicting preferred/seed topics.

## Acceptance criteria

1. Graph output is deterministic for identical Brand Brain input and sector pack.
2. Aliases/topics are normalized and deduplicated.
3. Confirmed Brand evidence takes precedence over inferred/sector-pack seed values.
4. Exclusions win topic conflicts.
5. Graph nodes preserve confidence/sourceIds where evidence exists and do not invent them otherwise.
6. Material graph changes advance the persisted version; identical fingerprints reuse the current version.
7. Sector packs exist for generic, AI/tech, Umrah, motorcycles and IAS/UPSC and are replaceable/configurable.
8. Hunter lineage can record the Brand Intelligence graph version without changing Hunter ranking behavior in this slice.
9. No frozen UI or publishing authority changes occur.
