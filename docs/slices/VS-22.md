# VS-22 — Research Evidence Enrichment

Status: Approved and active — bounded runtime implementation

## Goal
Strengthen Kairo research and novelty evaluation with authoritative public scholarly metadata/evidence from OpenAlex- and Crossref-style providers while preserving provider neutrality, provenance, Brand isolation and graceful degradation.

## Requirements
- FR-07 Duplicate and novelty intelligence.
- FR-20 Pilot operations and controls.

## Approved scope
- Add provider-neutral public research evidence adapters for OpenAlex and Crossref behind the existing `DiscoverySourceProvider` / `SourceRoutingToolGateway` boundary.
- Preserve `global-public` scope for every external scholarly query. Brand-private Brand Brain, Workspace context, credentials, prompts and private media must never be included in OpenAlex/Crossref requests.
- Let the Researcher optionally enrich its normal public web evidence with explicit public-only scholarly queries.
- Deduplicate evidence across general web, OpenAlex and Crossref using canonical URLs/DOIs before the model sees it.
- Preserve source/provider/version/retrieval provenance in the persisted Research Dossier.
- Bound result counts, response sizes and timeouts; classify provider failures and continue when one optional scholarly provider is unavailable.
- Keep OpenAlex API-key usage optional/configuration-owned by the adapter; never return or log the key.
- Use Crossref polite identification when an optional contact email is configured; never expose that operational contact in evidence.
- Add deterministic tests for normalization, privacy boundary, rate-limit/upstream degradation, deduplication and Researcher enrichment.

## Out of scope
- Sending Brand-private context to public evidence providers.
- Database schema migrations.
- New autonomous publishing or approval authority.
- Provider-specific types in the domain model.
- Full-text paywalled paper retrieval.
- Citation-network ranking or semantic embeddings.
- Release, deployment or production enablement.
- VS-23 or VS-24 activation.

## Acceptance criteria
1. OpenAlex and Crossref adapters implement the existing provider-neutral discovery contract and return normalized `DiscoveryEvidence` with provenance.
2. Both adapters reject any request whose scope is not `global-public` before network I/O.
3. External requests are bounded by result count, timeout and response size.
4. OpenAlex metadata prefers DOI URLs when present and safely reconstructs a bounded abstract when available.
5. Crossref metadata prefers DOI URLs, safely strips markup from abstracts and preserves title/publisher/author/publication metadata when available.
6. Provider rate-limit/upstream/timeout failures never echo API keys or private request data.
7. Researcher enrichment is opt-in through a separate `publicResearchQuery`; no Brand-private idea/context object is used to build external scholarly queries.
8. Failure of OpenAlex or Crossref degrades only that source; normal research can still complete when other evidence exists.
9. Evidence is deduplicated by canonical DOI/URL before Researcher invocation and persisted with stable evidence IDs.
10. Existing Researcher fabrication/first-person guards and the broader CI/security/product-intake gates remain green.
