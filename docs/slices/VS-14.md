# VS-14 — Marketing Lab Benchmark Foundation

Status: Approved; ready for implementation

## Goal
Establish the Kairo Marketing Lab so native Kairo capabilities, pinned external challengers and future skills can be compared on identical Brand-scoped inputs before any external capability is promoted.

## Requirements
- FR-09 Angle development
- FR-11 Content Studio metadata and generation provenance
- FR-12 Critic/Judge quality evaluation
- FR-16 Performance tracking
- FR-17 Performance Intelligence
- FR-18 Brand Learning
- FR-19 Experiments
- FR-20 Pilot Operations

## User/product outcome
Kairo gains an auditable answer to: **does this candidate marketing skill actually improve Kairo for this Brand and format?**

The foundation must support Kairo Native as the control, Corey Haines marketingskills as the first pinned challenger source, and future challengers without changing the benchmark contract.

## In scope
- Kairo-owned marketing Skill Manifest/Registry domain model.
- Explicit execution modes separating native runtime from reference-only and future sandboxed skills.
- Exact source provenance for external challengers: repository, commit SHA, path, content/blob hash and licence metadata.
- Benchmark cases that give each candidate the same Brand/audience/objective/opportunity/Claims/channel/format context.
- First-class CarouselPlan and ReelPlan benchmark artifact structures.
- Deterministic benchmark scoring inputs for Truth, Brand fit, hook quality, originality, format quality, human preference, edit distance, Critic score, latency, cost and real-world performance evidence.
- Staged verdicts: offline evaluation → shadow eligibility → live-experiment eligibility → Brand qualification.
- Hard gates that prevent a challenger with truth failures or insufficient paired evidence from being promoted.
- Corey reference manifests pinned to one reviewed upstream revision.
- Tests proving equal/ambiguous results keep the Kairo Native baseline.

## Explicit non-goals
- Do not vendor or install the full Corey repository.
- Do not execute arbitrary external skill instructions in production.
- Do not grant external skills network, secret, publishing or unrestricted Brand-context access.
- Do not replace Brand Brain with `.agents/product-marketing.md` or another external context model.
- Do not modify the Truth/Claims Gate, tenant isolation, human approval or publishing authority.
- Do not implement Instagram OAuth, Carousel publishing, Reel publishing, media rendering, webhooks or Insights in this slice.
- Do not auto-switch Brand skill selections based on one benchmark or one post.
- Do not add UI, API routes or database migrations.

## Benchmark principles
1. Same input for every contender.
2. Kairo Native is the control/baseline.
3. Truth is a hard gate, not a weighted marketing score.
4. A tie or unclear result keeps the baseline.
5. Quality gains must be material enough to justify added cost/latency/complexity.
6. Human preference and edit distance are captured when available.
7. Real-world performance requires comparable observations and is correlation evidence, not automatic causation.
8. Promotion is staged and auditable.
9. Qualification may be Brand/capability/format-specific; there is no universal winner requirement.
10. Upstream updates never change benchmark behavior automatically.

## Acceptance criteria
1. Reference-only external skills cannot be selected for runtime execution.
2. GitHub challenger manifests require an exact 40-character commit SHA and source provenance.
3. Native and challenger results can be compared using paired benchmark cases.
4. Truth failure blocks advancement regardless of other quality scores.
5. Insufficient, tied or immaterial evidence preserves Kairo Native.
6. A clearly better challenger can advance only to the next configured benchmark stage, not directly to production.
7. Reel and carousel plans are structurally validated and retain supporting Claim IDs.
8. Cost and latency regressions can block advancement unless explicitly allowed by benchmark policy.
9. Real-world performance is optional evidence until enough comparable samples exist.
10. No external skill obtains tools, secrets, publishing authority or unbounded Brand context in VS-14.
