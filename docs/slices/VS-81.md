## Outcome
Kairo provides faster discovery, clearer operational feedback and more complete accessible states on top of the VS-80 visual system without removing features.

## In scope — tasks 71–80
1. Add a Brand-scoped notification centre for approvals, publishing failures and connection problems.
2. Extend command search across Brands, Campaigns and Content Assets without eager shell-wide data loading.
3. Add reusable toast feedback with accessible status semantics and safe undo affordances where supported.
4. Add consistent Instagram/Facebook icons and readable health labels across connection and destination surfaces.
5. Add reusable skeleton loading states to primary routes.
6. Add deterministic Brand avatar/accent identity with accessible contrast.
7. Improve empty, partial, error, reconnect and success states with one recommended action.
8. Improve keyboard behavior, dialog focus, mobile touch targets and screen-reader labeling.
9. Add accessible notification/search/theme behavior on mobile without crowding primary navigation.
10. Expand deterministic UI, theme, responsive and accessibility regression coverage.
