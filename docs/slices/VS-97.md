# VS-97 — Home Hunter Recommendations Trigger

## Goal

Let the user explicitly ask Kairo for fresh recommendations from Home without exposing Hunter as a separate primary workflow.

Approved interaction:

```text
Home → For You → Get recommendations
  → Hunter runs for the active Brand
  → approved public discovery/source routing
  → evidence-linked candidate judgment
  → existing qualification + deduplication
  → Brand Opportunities persisted
  → Home refreshes For You
```

`AI Generate` is not part of this action. Generation remains downstream after the user chooses an idea/recommendation.

## Requirements

- FR-03 — Brand Brain
- FR-06 — Hunter / Discover
- FR-07 — Duplicate and novelty intelligence

## Acceptance criteria

1. Home exposes one clear `Get recommendations` action when For You is empty and `Refresh recommendations` when recommendations already exist.
2. The action is Brand-scoped and authenticated.
3. The API invokes the existing HunterOrchestrator, existing Brand Intelligence projection/source policy, existing public discovery adapters and existing DiscoveryService persistence rules.
4. A successful Hunter run may legitimately return zero qualified Opportunities; the UI must say so truthfully and must not fabricate filler.
5. Concurrent duplicate clicks during one in-process run reuse the active run instead of starting another model/tool execution.
6. After the run completes, Home refreshes and renders newly persisted qualified Opportunities through the existing `getOpportunities → buildForYou` path.
7. My Idea's current format-selection action is renamed to `Recommend format` so Hunter discovery and content-format recommendation are not conflated.
8. Provider/source degradation remains visible as a compact truthful status and does not fabricate success.
9. No database migration, credential-scope change, publishing authority, autonomous publishing or cross-Brand data sharing is introduced.

## Out of scope

- Scheduled/continuous Hunter jobs.
- New paid discovery providers.
- New database schema for durable Hunter jobs.
- A new Discover primary navigation destination.
- AI content generation from the button itself.
- Automatic publishing.

## Verification

- API route tests for authentication, unavailable runtime and successful Brand-scoped invocation.
- Worker/domain behavior is reused rather than reimplemented.
- Web typecheck/build validates the Home action and proxy route.
- Repository governance validation, preflight, CI and security gates must pass before certification.
