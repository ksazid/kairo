# VS-104 — Batch 7 Closed-Loop Recommendations

## Objective

Complete the user-visible intelligence loop from Brand confirmation and Hunter discovery through For You feedback and development, while preserving source, Idea, Campaign, publish, performance and learning lineage.

## In scope

- Trigger the first Hunter run automatically after Brand Brain confirmation.
- Use the persisted Brand Intelligence Topic Graph/version and the existing Source Intelligence Hunter path.
- Surface qualifying Hunter Opportunities through the existing Home `For you` experience.
- Persist Save, Ignore/Discard, Seen and Develop behavior without redesigning the frozen Home UI.
- Treat Ignore as durable dismissed feedback while preserving the existing visible label.
- Make Develop create or reuse exactly one Brand-scoped Idea with `source_type=opportunity` and `opportunity_id` lineage.
- Preserve that linked Idea when a For You recommendation enters the existing Simple Creation flow, so Campaign and Content remain attributable to the originating Opportunity.
- Feed owner-accepted performance Learnings and prior opportunity choices/feedback into the next Brand-private Hunter judgment context.
- Keep My Idea URL research on the existing shared Source Intelligence router rather than introducing a second ingestion path.
- Add durable, tenant-scoped recommendation feedback persistence and audit events.
- Preserve bounded retries, source degradation, deduplication and current publishing approval controls.

## Out of scope

- Scheduler or Scheduled Hunter execution (Batch 8).
- Autonomous publishing or any relaxation of human approval.
- New OAuth scopes or connector authority.
- A new scraping/retrieval pipeline.
- Frozen visual redesign. Existing controls may be enabled or wired without changing approved hierarchy or styling.

## Privacy and safety

- Accepted Brand performance learning and recommendation feedback are Brand-private context.
- Private learning is not copied into public search/provider queries and is not treated as public evidence.
- Tenant access is checked before feedback, development or Hunter execution.
- Seen feedback is best-effort enrichment and must never break reading the recommendation surface.
- Dismissal suppresses the Opportunity by moving it to the existing ignored state.
- Develop is idempotent: repeated execution reuses the existing opportunity-linked Idea.

## Acceptance criteria

1. Confirming onboarding attempts the Brand's first Hunter run automatically and safely degrades if Hunter is temporarily unavailable.
2. Hunter continues to use persisted Topic Graph/version lineage and the existing Source Intelligence discovery/fetch path.
3. Accepted performance Learnings and prior Save/Ignore/Develop/Seen/Dismissed behavior are consumed by the next Brand-private Hunter run.
4. Home `For you` records Seen feedback and the existing bookmark control persists Save without visual redesign.
5. Ignore persists the existing ignored state and a durable dismissed feedback event.
6. Develop creates or reuses exactly one opportunity-linked Idea and can continue through Research/Angles.
7. For You AI Generate reuses that linked Idea in Simple Creation so Campaign/Content lineage points back to the Opportunity.
8. My Idea URLs continue through the shared Source Intelligence router used by Research.
9. Recommendation feedback is idempotent, tenant-isolated and auditable.
10. Clean PostgreSQL 18 migrations, affected tests, TypeScript/preflight, runtime verification, dashboard build and security checks pass.
11. Production migration and deployment are verified, followed by a representative authenticated closed-loop smoke before the slice is called complete.
