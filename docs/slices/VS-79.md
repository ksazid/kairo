# VS-79 — Simple Product Journey

## Status
Approved for runtime implementation by Sazid Khan on 2026-08-22 as Batch 6.

## Outcome
Kairo defaults to a goal-first `Create → Review → Publish → Results` journey while preserving Idea, Research, Claims, Angles, Campaign, Content, Critic, Approval, Publish and Learning as the underlying architecture and optional Advanced details.

## In scope — Batch 6 tasks 51–60
1. Replace the object-first home entry with “What are you trying to achieve today?” and goal choices.
2. Accept a description, topic, product URL, Instagram post or website from one Create surface.
3. Recommend Post, Reel, Carousel or Campaign when the user does not choose a format.
4. Orchestrate Idea → Research → Angle → Campaign → Content behind one friendly progress model.
5. Show the recommended direction plus two alternatives and an optional “Why this direction?” view.
6. Present actual finished media, caption, hook, destination and publish timing in Review.
7. Add one dominant CTA per screen plus a persistent responsive Next-step bar.
8. Present Publish now/Schedule with exact approved asset and Instagram destination readiness.
9. Combine Performance and Learning into Results with “Create another like this”.
10. Simplify navigation to Home, Create, Library, Calendar, Results and Brand while preserving Advanced details links.

## Acceptance criteria
- [x] Default navigation exposes only the six simplified product concepts.
- [x] Create starts from a goal and allows links or rough text without requiring internal objects.
- [x] Kairo recommends a format but respects an explicit user format choice.
- [x] Research/evidence/strategy remain persisted and accessible through Advanced details.
- [x] Friendly progress never claims completion before the underlying stage completes.
- [x] Review shows rendered media and trust evidence rather than generated text alone.
- [x] Exactly one visually dominant forward CTA is present per primary screen.
- [x] Publish uses the approved immutable version and connected destination.
- [x] Results combines metrics and accepted Learning with causal restraint.
- [x] Full runtime, build and governance verification pass before merge approval.
