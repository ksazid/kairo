# VS-74 — Brand Source Onboarding & Brand Brain Enrichment

## Status
Approved for runtime implementation by Sazid Khan on 2026-08-22.

## Requirements
- FR-02 — Brand creation
- FR-03 — Brand Brain
- FR-04 — Knowledge and sources
- FR-05 — Channels
- FR-20 — Pilot Operations and Controls

## Outcome
First-run and additional-Brand onboarding offer distinct **Paste website** and **Connect Instagram** paths. Both remain manageable inside Brand Brain after onboarding and feed source-backed, owner-reviewable Brand Brain suggestions.

## In scope
1. Keep Website and Instagram as permanent Brand Brain sources.
2. Offer Paste Website and Connect Instagram during onboarding.
3. Reuse the same source boundaries from onboarding and Brand Brain refresh.
4. Reuse the approved Meta OAuth flow and secure credential vault.
5. Detect linked Instagram Professional accounts with explicit selection when needed.
6. Import bounded Instagram profile/business metadata and recent media context without exposing credentials.
7. Preserve bounded SSRF-safe website extraction.
8. Analyze recent Instagram captions/media types as untrusted Brand evidence.
9. Propose source-backed positioning, audience, voice, visual direction and content patterns without overwriting confirmed fields.
10. Present imported suggestions for owner review and editing.

## Acceptance criteria
- [x] Website and Instagram appear as separate onboarding choices and remain visible/manageable in Brand Brain.
- [x] OAuth begins only after an authorized Brand exists and safely returns to Brand Brain onboarding.
- [x] Only eligible Instagram Professional accounts are selectable; multiple candidates require explicit choice.
- [x] Provider tokens never enter Brand Brain, prompts, logs, API responses or browser-visible state.
- [x] Instagram import is bounded, idempotent, Brand-scoped and records active Knowledge provenance.
- [x] Website retrieval retains the existing HTTP(S)-only SSRF, redirect, byte and timeout controls.
- [x] Recent captions/media types may inform proposals but are always treated as untrusted evidence.
- [x] Confirmed Brand Brain fields are never overwritten by import or refresh.
- [x] Inferred fields retain active source IDs and remain editable/confirmable in Review & Control.
- [x] Cross-Brand source, connection and import access returns safe not-found behavior.
- [x] Deterministic tests, security checks, preflight and runtime verification pass.

## Explicit exclusions
- no consumer/personal Instagram accounts;
- no new Meta permissions, Ads, Stories, DMs or engagement automation;
- no autonomous publishing;
- no token or credential data in Brand Brain;
- no silent confirmation of inferred facts;
- no cross-Brand learning or data sharing;
- no release, deployment or production enablement without exact-SHA human approval.
