# VS-18 — Creative Asset Production

**Status:** approved / implementing  
**Risk:** medium  
**Implementation mode:** runtime-enabled

## Outcome
Kairo can materialize its existing Claim-linked carousel and Reel plans into deterministic generated-media artifacts suitable for private storage and downstream approved publishing.

## Acceptance criteria
1. Carousel renderer validates the plan before rendering and emits one deterministic PNG per slide.
2. Carousel artifacts retain Workspace, Brand, source-plan fingerprint, slide index and supporting Claim IDs.
3. Reel renderer validates timing/Claim lineage and emits deterministic storyboard PNG frames plus a canonical timed render manifest.
4. Rendering the same plan/theme produces byte-identical artifacts and hashes.
5. Renderer never adds factual copy beyond the validated plan text.
6. Generated-media store accepts only bounded content types/sizes and returns opaque object identifiers; public URLs are not authoritative storage identity.
7. Asset production service is idempotent by Workspace/Brand + source fingerprint + renderer version.
8. Failure is explicit and cannot mark a content version approved/published.
9. No new external media/AI provider, unrestricted shell, autonomous publish, release or production-enable path is added.
10. Tests cover invalid lineage, unsafe dimensions/size bounds, deterministic hashes, tenant/Brand metadata and idempotency.

## Explicit exclusions
- final MP4 encoder/provider selection;
- AI image/video generation;
- voice synthesis;
- stock-media search;
- browser/shell rendering;
- Stories/mixed-video carousel;
- autonomous publishing;
- release/deployment/production enablement.
