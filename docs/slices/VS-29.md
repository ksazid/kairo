# VS-29 — Guided Brand Brain Redirect Correction

## Status
Approved for bounded runtime implementation by Sazid Khan on 2026-08-16T08:08:00+02:00 after reproducing the Brand Brain `NEXT_REDIRECT` banner.

## Requirement
- FR-03 — Brand Brain

## Problem
The guided Brand Brain server action calls Next.js `redirect()` inside the same `try` block that handles Brand Brain build failures. Next.js implements `redirect()` by throwing an internal redirect signal. The action catches that signal as if it were an application failure and redirects again with `NEXT_REDIRECT` in the error query, which surfaces as the red error banner when the owner selects **Refresh suggestions**.

## Outcome
A successful or safely degraded Brand Brain refresh redirects once to the normal notice state. A genuine Brand Brain build failure redirects once to the bounded error state. Next.js redirect control flow must never be converted into a user-facing Brand Brain error.

## Acceptance criteria
- [ ] A successful `buildBrandBrain` call causes exactly one redirect to the Brand Brain page with a `notice` query.
- [ ] The Next.js redirect signal is not caught and transformed into an `error=NEXT_REDIRECT` redirect.
- [ ] A genuine `buildBrandBrain` failure still causes exactly one redirect with a bounded user-visible error query.
- [ ] Existing objective, public reference and owner-boundary request construction remains unchanged.
- [ ] No API, domain, database, authentication, authorization, infrastructure or deployment behaviour changes.
- [ ] Regression coverage proves the redirect is issued only once on the success path.
