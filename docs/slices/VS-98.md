# VS-98 — Approved Home Creation Recovery

## Goal

Correct the Home creation UI and media flow so it matches the Product Owner-approved functionality without expanding this recovery into URL-ingestion or Hunter-quality work.

Approved My Idea flow:

```text
My Idea
  → text / URL / Photo / Video / Media
  → Auto selects the best supported format
  → user may override Post / Carousel / Reel / Video
  → optional eligible Presenter
  → AI Generate
  → Content Preview
```

Approved For You UI flow for already-persisted opportunities:

```text
For You
  → recommendation shows Post / Carousel / Reel / Video
  → choose idea
  → compact format / optional Presenter controls
  → AI Generate
  → Content Preview
```

## Requirements

- FR-09 — Angle development
- FR-11 — Content Studio
- FR-18 — Brand Learning where already available to Auto-format selection

## Acceptance criteria

1. `Recommend format` is removed from My Idea. There is no user-visible format-recommendation step.
2. Format controls are always visible as `Auto`, `Post`, `Carousel`, `Reel`, `Video`; `Auto` is the default and Kairo resolves a recommended supported format from the current input while preserving explicit user override.
3. The dominant creation CTA is `AI Generate`; successful creation proceeds directly to the existing Content Preview route without exposing Research, Strategist, Campaign or other technical workflow objects.
4. URL remains an optional My Idea input using the existing URL/research capability. This slice does not expand scraping, site-specific fallbacks or arbitrary-URL ingestion. If the existing reader cannot use the URL, Home returns a clear user-facing failure state instead of pretending the URL was learned.
5. Photo and Video uploads use the existing private S3-compatible object-storage boundary (Cloudflare R2 in production), short-lived signed PUT/GET URLs, Brand-scoped object keys and PostgreSQL metadata.
6. Every successfully uploaded Photo/Video is automatically reusable through `Media`; selecting an existing Media item attaches it without copying or re-uploading the binary.
7. Creation requests persist and validate `mediaAssetIds[]`; cross-Workspace/cross-Brand media IDs fail closed.
8. Presenter remains a separate Brand-scoped domain object. The Home Presenter control appears only for Reel/Video when an eligible Presenter exists; `None` remains available and server-side eligibility is authoritative.
9. For You cards expose their recommended Post/Carousel/Reel/Video type and can generate directly from the card through compact controls and `AI Generate` using already-persisted opportunities.
10. Existing `Get recommendations` / Hunter behavior is unchanged by this slice. Hunter source coverage, qualification quality, zero-result behavior and Brand Intelligence improvements are explicitly deferred.
11. URL onboarding, Brand Intelligence Context refactors and source-specific scraping/fallback improvements are explicitly deferred.
12. Home visual hierarchy, Kairo tokens, five-destination shell, calm minimal design and responsive/accessibility behavior remain unchanged except for the approved controls.
13. No publishing authority, provider credential scope, autonomous publishing or hidden reasoning exposure is introduced.

## Required evidence before certification

- Authenticated My Idea text → Auto format → AI Generate → Content Preview.
- Authenticated My Idea URL → existing URL path → Content Preview when readable, plus truthful user-facing failure when the current reader cannot use it.
- Photo upload → private storage → attached Media → AI Generate → Content Preview.
- Video upload → private storage → attached Media → AI Generate → Content Preview.
- Uploaded media reappears in Media without binary duplication.
- Cross-Brand media rejection.
- Presenter show/hide behavior for Reel/Video.
- Existing For You opportunity → compact format/Presenter controls → AI Generate → Content Preview.
- Responsive and accessibility checks for changed Home controls.

## Explicitly deferred

- URL onboarding extraction/scraping reliability and source-specific fallback design.
- Arbitrary URL scraping improvements from My Idea beyond the current existing reader.
- Canonical Brand Intelligence Context / agent-context propagation work.
- Hunter discovery-provider expansion, source routing changes, qualification improvements or positive-result guarantees.
- Any claim that `Get recommendations` has been fixed by VS-98.

## Release boundary

Implementation authorization does not authorize certification, merge, release, production enablement or deployment. Those remain separate exact-SHA gates.
