# VS-98 — Approved Home Intelligence Recovery

## Goal

Correct the production Home creation and discovery flow so it matches the Product Owner-approved functionality instead of the incorrect VS-97 interaction contract.

Approved creation flow:

```text
My Idea
  → text / URL / Photo / Video / Media
  → Auto selects the best supported format
  → user may override Post / Carousel / Reel / Video
  → optional eligible Presenter
  → AI Generate
  → Content Preview
```

Approved recommendation flow:

```text
For You → Get recommendations
  → Brand Intelligence-aware Hunter
  → truthful public evidence discovery
  → qualified Brand Opportunities
  → choose an idea
  → compact format / optional Presenter controls
  → AI Generate
  → Content Preview
```

## Requirements

- FR-02 — Brand creation
- FR-03 — Brand Brain
- FR-04 — Knowledge and sources
- FR-06 — Hunter / Discover
- FR-07 — Duplicate and novelty intelligence
- FR-09 — Angle development
- FR-11 — Content Studio

## Acceptance criteria

1. `Recommend format` is removed from My Idea. There is no user-visible format-recommendation step.
2. Format controls are always visible as `Auto`, `Post`, `Carousel`, `Reel`, `Video`; `Auto` is the default and Kairo continuously resolves a recommended supported format from current input while preserving explicit user override.
3. The only dominant creation CTA is `AI Generate`; successful creation proceeds directly to the existing creation/Content Preview path without exposing Research, Strategist, Campaign or other technical workflow objects.
4. Photo uploads and Video uploads use the existing private S3-compatible object-storage boundary (Cloudflare R2 in production), short-lived signed PUT/GET URLs, Brand-scoped keys and PostgreSQL metadata.
5. Every successfully uploaded Photo/Video is automatically reusable through `Media`; selecting an existing Media item attaches it without copying or re-uploading the binary.
6. Creation requests persist and validate `mediaAssetIds[]`; cross-Workspace/cross-Brand media IDs fail closed.
7. Presenter remains a separate Brand-scoped domain object. The Home Presenter control appears only when the selected format can use an eligible Presenter; `None` remains available and server-side eligibility is authoritative.
8. For You cards expose their recommended Post/Carousel/Reel/Video type. Choosing a recommendation keeps generation on Home through compact controls and `AI Generate` rather than requiring a technical intermediate page.
9. Hunter uses canonical current Brand Intelligence. A Brand with insufficient learned context is reported truthfully instead of being treated as richly learned.
10. Existing RSS discovery support is wired into Hunter where the approved source registry/sector pack requests it. Source degradation is surfaced; zero worthwhile opportunities remains valid and no filler is fabricated.
11. URL onboarding persists the public reference as normal Brand/Knowledge provenance when readable, persists inferred Brand Brain fields when supported, and clearly retains `learning-limited` when the source cannot be learned (including sites that block generic public retrieval).
12. A canonical, versioned Brand Intelligence Context is projected from authoritative Brand state and supplied to Brand-private Hunter/Researcher/Strategist/Drafter/Critic executions through application-owned boundaries; agents do not query persistence directly.
13. User-confirmed Brand facts remain authoritative and no private Brand intelligence crosses Brand boundaries.
14. Home visual hierarchy, Kairo tokens, five-destination shell, calm minimal design and responsive/accessibility behavior remain unchanged except for the approved controls.
15. No publishing authority, provider credential scope, autonomous publishing or hidden reasoning exposure is introduced.

## Required end-to-end evidence before certification

- Authenticated URL onboarding → Brand Intelligence → Home → Photo/Video/Media → Auto format → optional Presenter → AI Generate → Content Preview.
- Authenticated Hunter → For You → choose idea → AI Generate → Content Preview.
- Cross-Brand media rejection.
- Brand learning-limited state for a blocked public source.
- Hunter truthful zero/degraded state and positive persisted-opportunity path.
- Responsive and accessibility checks for changed Home controls.

## Release boundary

Implementation authorization does not authorize certification, merge, release, production enablement or deployment. Those remain separate exact-SHA gates.
