# VS-83 — Production Object Storage and Live Carousel Verification

## Status
Implementation approved on 2026-08-22. The Product Owner additionally approved the bounded Instagram carousel Publish now control on 2026-08-23.

## Outcome
Kairo renders approved Instagram carousels into private production object storage, exposes only bounded signed delivery URLs, and verifies that Meta publishes the exact approved asset version.

## In scope — combined batch
1. Add a replaceable S3-compatible private creative object adapter.
2. Upload rendered slides, thumbnails and manifests with immutable content-addressed keys.
3. Add deterministic SigV4 temporary delivery for private objects.
4. Add an authenticated server-side carousel render action.
5. Run the existing measured quality checks against the actual rendered PNGs.
6. Persist the render, slide, thumbnail and manifest lineage as one ready asset version.
7. Fail closed on unsafe storage configuration, object hashes, dimensions or blocking quality findings.
8. Make Review and publishing consume the same signed private objects.
9. Extend production configuration and smoke verification for exact approved carousel media.
10. Complete one provider-backed carousel publish and verify Meta media ID, URL, Calendar and Results.
11. Expose Publish now for an approved Instagram carousel only when the connected destination advertises carousel publishing capability, reusing the existing exact-version publishing action.

## Acceptance criteria
- [x] Storage credentials never enter URLs, logs, persisted render records or client responses.
- [x] Private objects use immutable Brand-scoped keys and server-verified SHA-256 hashes.
- [x] Signed delivery is HTTPS, host-bound, time-bounded and read-only.
- [x] Rendering produces 1080x1350 PNG slides and a deterministic thumbnail.
- [x] Blocking quality findings prevent a ready render from being approved.
- [x] Render records bind the manifest, every slide and thumbnail to the exact project revision.
- [x] Review previews and Meta publishing resolve the same approved object keys.
- [x] Tenant isolation and optimistic concurrency remain enforced.
- [x] The approved Instagram carousel surface exposes Publish now only for a matching connected carousel-capable destination.
- [ ] A provider-backed carousel reaches Published with Meta result evidence.
- [x] Runtime, build, security and governance checks pass before exact-SHA merge approval.
