# VS-106 — Brand DNA Readiness-Gated Onboarding

## Scope

Preserve Kairo's one-public-link, multi-source onboarding while adding a deterministic Brand DNA readiness checkpoint before Hunter activation.

## Approved behaviour

- Existing Website, Instagram, LinkedIn, YouTube, product, blog and public-page onboarding remains available.
- Inferred Brand Brain fields remain inferred until the owner edits or explicitly confirms them.
- Readiness requires usable business context, offerings, audience, positioning, core/related topics and boundaries. Geography is conditional for location-dependent Brands.
- Generic fallback/placeholder values do not satisfy readiness.
- The confirmation screen presents one highest-value enrichment action at a time.
- Hunter runs only after readiness is ready.
- Existing confirmed fields and multi-source evidence remain authoritative and Brand-scoped.

## Exclusions

No new provider, OAuth scope, publishing authority, scheduler, PDF workflow or autonomous Hunter behaviour is introduced.

## Verification

Deterministic domain and API tests, workspace/Brand isolation checks, web typecheck, governance/preflight and exact-SHA certification remain required before release.
