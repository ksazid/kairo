# Assumptions

Only assumptions already approved in the Kairo venture package are carried into PES:

- Initial ICP: creators, founders and lean operators managing approximately 2–10 active Brands/pages.
- Web is the primary V1 client; native mobile follows later unless separately approved.
- PostgreSQL is authoritative business state.
- Qdrant/TurboQuant is a preferred semantic direction, not a promoted dependency until benchmarked.
- Hermes is preferred but replaceable; DirectModelRuntime remains viable.
- Paperclip is evaluation-only and is not an implementation dependency.
- Instagram and LinkedIn are pilot channel targets subject to exact API feasibility.
- Text-centric AI inference target is approximately under $5 per active Brand/month, excluding premium media/connectors.

No unapproved provider, pricing, deployment vendor or identity provider is assumed.
