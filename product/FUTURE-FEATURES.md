# Kairo Future Features

> Status: **Deferred / non-authoritative**
>
> This file is a product parking lot for capabilities that may be considered later. An item appearing here does **not** expand the approved PRD, authorize implementation, create a vertical slice, or grant release approval. Any item selected for implementation must first be promoted through Kairo's normal product/governance process.

## Publishing, distribution and performance

Capabilities identified for later consideration from the Post Bridge product review on 2026-08-16:

- **Unified multi-channel Publishing Gateway** — one deterministic publishing layer for supported social/content destinations.
- **Platform-specific Content Adapter** — adapt approved campaign content to each channel's format, metadata and publishing constraints.
- **Visual Content Calendar** — unified scheduled/published content timeline across Brands, campaigns and channels.
- **Cross-platform Performance / Analytics Ingestion** — normalize supported channel metrics so Kairo's performance intelligence and learning loop can use them.
- **Channel / Account Groups** — reusable groups of destination accounts/channels for faster campaign distribution.
- **Format Intelligence Library** — reusable content-format patterns enriched over time with Brand-specific performance learning.
- **Kairo Action API** — governed external API surface for approved Kairo actions and integrations.
- **Kairo MCP Server** — controlled MCP interface for external AI clients/agents to access approved Kairo capabilities.
- **Media Transformation Pipeline** — deterministic resizing, cropping, transcoding, thumbnail and platform-preparation workflows.
- **Video Creation / Editing Tooling** — later-stage video composition/editing capabilities integrated with Kairo campaigns.

## Promotion rule

Before any capability above becomes active work, determine whether it is already covered by an approved PRD requirement or requires a PRD/decision update, then create or update the governed delivery slice with explicit scope and implementation approval.
